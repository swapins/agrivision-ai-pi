# AgriVision AI — MobileNetV2 Plant Health Classifier

This model is prepared for the **AgriVision AI** school smart-farming project by Isis Saritha Swapin / PeachBot.

## Intended use

Local leaf-image classification on a Raspberry Pi + Google Coral USB Accelerator demonstration. The release may contain:

- `plant_health_int8.tflite` — full-integer TFLite before Edge TPU compilation.
- `plant_health_edgetpu.tflite` — Edge TPU-compiled deployment artifact, when compiled successfully.
- `labels.txt` — output labels.
- `model_manifest.json` — exact architecture, dataset, split and evaluation metadata.

## Base architecture

MobileNetV2 alpha 0.35, 224×224 RGB. The model is chosen for low compute cost and compatibility with integer edge inference.

## Dataset

The default training pipeline uses `geraldmc/plantvillage-full`, preserving its held-out leaf-grouped test assignment. The model card must be updated with the exact manifest metrics generated by training.

## Important limitation

PlantVillage images are largely captured under controlled backgrounds. Strong held-out performance on this dataset does **not** establish robustness in real farms. This is a school/research prototype, not a crop-diagnosis device. Predictions should be phrased as possible visible disease/problem and confirmed by appropriate agricultural expertise.

## Reproducibility

Training and TFLite export code is in the accompanying AgriVision AI GitHub repository. See `training/train_tf_mobilenetv2.py` and `training/compile_edgetpu.sh`.
